DATASET PROPIO

Dataset Studio

Importa fotos reales, revisa cada sugerencia y aprueba manualmente la caja y la clase. Una predicción automática nunca cuenta como revisada.

1. Capturar o importar

Selecciona fotos o una carpeta. En móvil, el botón de cámara abre la cámara trasera. Cada archivo conserva procedencia y licencia.

2. Cola de revisión

Importa y abre una imagen para dibujar una caja.

Arrastra sobre el objeto. Puedes pulsar una sugerencia de YOLO y luego ajustar la caja dibujándola de nuevo.

3. Corregir y aprobar

Marca vértices en la imagen o presegmenta a partir de una caja. Revisa y edita el contorno: es una propuesta, no una máscara precisa garantizada.
